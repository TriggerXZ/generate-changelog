generate-changelog

A self-contained bash script that turns your git history into a beautiful, Keep-a-Changelog-formatted CHANGELOG.md — automatically.

What it does

You commit code. You make tags. generate-changelog reads your git log, categorizes every commit into Added / Fixed / Changed / Removed, and writes a CHANGELOG.md your users will actually read.

$ bash changelog.sh
changelog.sh: wrote CHANGELOG.md (version 1.2.4, 17 commits)
  Added:    8
  Fixed:    4
  Changed:  5
  Removed:  0
  Breaking: 1

Why you'll love it

Zero dependencies

Just bash, git, and awk. No npm, no Python, no Node. Works on macOS, Linux, and Git Bash on Windows.

Conventional commit aware

Recognizes feat, fix, refactor, perf, docs, and more. Heuristic fallback handles non-conventional repos.

BREAKING CHANGE detection

Commits with ! or BREAKING CHANGE get a dedicated warning section. Your users see the impact before upgrading.

Smart version inference

Reads your last git tag (v1.2.3) and auto-bumps to 1.2.4. Override with --version 2.0.0 when you need to.

Idempotent

Run it twice for the same version — the script refuses to duplicate the section. Run it in CI without fear.

Safety first

Refuses to run on a dirty working tree (so it can't mix uncommitted work with your changelog). Bypass with --allow-dirty.

Real output

Tested against a 10-commit synthetic repo with mixed conventional and non-conventional commits. The full test suite (7 scenarios) is in SAMPLE_OUTPUT.md.
